### 🧩 ¿En qué me enfoco?

* 🎶 **Rhythm Games & Modding:** Motores personalizados de Friday Night Funkin' (Psych Engine, Haxe/Lua), mods para Geometry Dash, y proyectos inspirados en Project: RUSHER.
* 🕹️ **Desarrollo de Videojuegos:** Creación de juegos en **Godot Engine 4** y **Roblox Studio** (Luau).
* 🐧 **Linux & Hardware:** Apasionado del software libre, scripting en **Fedora Linux** y experimentación con electrónica en **Arduino**.
* 🌐 **Desarrollo Web:** Interfaces web minimalistas, optimizadas e interactivas creadas con HTML, CSS y JavaScript.
